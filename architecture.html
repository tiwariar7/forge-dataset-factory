Pipeline Architecture

A deep dive into ForgeDataset's 6-stage extraction, hybrid chunking, and quality gate.

Stage 1: Intelligent Ingestion Router

Raw enterprise documents cannot be extracted uniformly. ForgeDataset inspects file signatures and routes each file to specialized native engines:

  • Excel / Spreadsheets (.xlsx, .xls): Processed by OpenPyXLEngine to capture exact formula relationships, multi-sheet references, and cell coordinates.
  • PDFs & Word Docs (.pdf, .docx): Processed by DoclingParser for layout-aware reading order and table bounding.
  • Scanned Documents: Routed to OCR fallback with quality scoring.

Stage 2: Zero-Overlap Hybrid Chunker

Traditional sliding-window chunkers introduce repeated tokens and fragment semantic concepts. ForgeDataset's HybridChunker guarantees:

  • Heading Path Provenance: Every chunk retains its hierarchy path (e.g. ['Financials', 'Q3', 'Gross Margin']).
  • Zero Overlap: No token overlap between chunks, preventing repetitive training noise in downstream fine-tuned models.
  • Table Header Duplication: When large tables span multiple chunks, table headers are preserved at the top of every split chunk.

Stages 3 & 4: Evidence-Grounded Generation & Quality Gate

Every candidate instruction-response pair generated by SFTGenerator passes through a multi-filter verification gate:

⚠️ Non-Negotiable Evidence Rule
If the generated response does not contain an exact verbatim character match from the source chunk, it is rejected immediately. No hallucinated claims can enter the dataset.

Additionally, NumericValidator executes a symbolic scan to verify that all numbers, statistics, percentages, and units present in the answer actually exist in the source document.

Stages 5 & 6: Deduplication & Split Export

SemanticDeduplicator uses fast cosine similarity over sentence embeddings to prune semantically identical questions. DatasetExporter performs **document-level train/validation/test splitting** so that no chunks from the same document appear in both training and test sets.
