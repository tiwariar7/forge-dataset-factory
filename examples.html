Real-world scenarios and domain-specific dataset generation pipelines.

Recipe 1: Processing Financial 10-K Reports

Financial filings contain dense tables and critical numbers. ForgeDataset's NumericValidator ensures no metrics are fabricated:

financial_pipeline.py
from ForgeDataset import IngestionRouter, HybridChunker, SFTGenerator, QualityGate, DatasetExporter

# 1. Ingest 10-K PDF
doc = IngestionRouter().route("sec_filing_10k.pdf")

# 2. Chunk with table header duplication
chunker = HybridChunker(max_source_context=500, repeat_table_headers=True)
chunks = chunker.chunk_document(doc)

# 3. Generate with Qwen 2.5 7B
generator = SFTGenerator(engine="ollama", model="qwen2.5:7b-instruct")
gate = QualityGate()

pairs = []
for chunk in chunks:
    for candidate in generator.generate_from_chunk(chunk):
        res = gate.evaluate(candidate, chunk)
        if res.status == "approved":
            pairs.append((res, chunk))

# 4. Export Alpaca formatted dataset
DatasetExporter(output_dir="data/financial").export(pairs, format_type="alpaca")

Recipe 2: Generating SFT Data from Excel Models

Spreadsheets contain cell values and formulas. ForgeDataset parses workbook matrices directly:

excel_pipeline.py
from ForgeDataset import IngestionRouter, HybridChunker, SFTGenerator, QualityGate, DatasetExporter

doc = IngestionRouter().route("budget_forecast_2026.xlsx")
# Extracted elements preserve cell coordinates, titles, and formula dependencies
chunks = HybridChunker().chunk_document(doc)

generator = SFTGenerator(engine="heuristic") # Zero dependency run
pairs = [(cand, c) for c in chunks for cand in generator.generate_from_chunk(c)]

DatasetExporter(output_dir="data/excel").export(pairs, format_type="sharegpt")
