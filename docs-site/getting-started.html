Getting Started

Install ForgeDataset and generate your first fine-tuning dataset in under 2 minutes.

1. Installation

ForgeDataset is a pure Python library compatible with Python 3.9 through 3.12.

Terminal
pip install forge-dataset-factory
Terminal (GGUF in-process support)
pip install "forge-dataset-factory[llamacpp]"
Terminal (FastAPI server + llama.cpp + dev tools)
pip install "forge-dataset-factory[all]"
Offline Testing Note
If you want to run ForgeDataset in CI/CD or offline without setting up Ollama or downloading GGUF models, you can use the built-in engine="heuristic" option.

2. First SFT Dataset in Python

Here is the complete end-to-end Python pipeline:

my_first_pipeline.py
from ForgeDataset import (
    IngestionRouter,
    HybridChunker,
    SFTGenerator,
    QualityGate,
    DatasetExporter,
)

# Step 1: Intelligent Ingestion (PDF, DOCX, XLSX, Markdown, CSV)
router = IngestionRouter()
doc = router.route("my_document.pdf")
print(f"Extracted {len(doc.elements)} elements via {doc.extracted_by.value}")

# Step 2: Zero-overlap Hybrid Chunking
chunker = HybridChunker(max_source_context=600, overlap=0)
chunks = chunker.chunk_document(doc)
print(f"Created {len(chunks)} contextual chunks")

# Step 3: Candidate SFT Generation with Traceable Evidence
generator = SFTGenerator(engine="ollama", model="qwen2.5:7b-instruct")
gate = QualityGate()

approved_pairs = []
for chunk in chunks:
    candidates = generator.generate_from_chunk(chunk)
    for candidate in candidates:
        evaluated = gate.evaluate(candidate, chunk)
        if evaluated.status == "approved":
            approved_pairs.append((evaluated, chunk))

# Step 4: Export to Alpaca format
exporter = DatasetExporter(output_dir="output")
result = exporter.export(approved_pairs, format_type="alpaca", prefix="finance_qa")

print(f"Exported {result['approved_count']} approved samples to output/")

3. Command-Line Interface (CLI)

You can also generate datasets directly from your terminal using the forge-dataset command:

Terminal
# Process any file directly to Alpaca format JSONL
forge-dataset process quarterly_report.pdf --engine ollama -o dataset.jsonl

# Process using in-process GGUF model (no server!)
# Process using in-process GGUF model (no server required)
forge-dataset process specs.docx --engine llama_cpp --model models/qwen.gguf

# Check which engines are active
forge-dataset engines
