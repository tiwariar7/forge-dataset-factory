⚡ 100% Local Synthetic Dataset Engine

Build SFT datasets
directly from enterprise docs.

ForgeDataset is the Python library for generating high-precision Supervised Fine-Tuning datasets with zero cloud fees, multi-engine local LLM support, and non-negotiable character-level evidence grounding.

Get Started Explore Architecture
$ pip install forge-dataset-factory

Why ForgeDataset?

Built for machine learning engineers who need high-signal training data without vendor lock-in.

🧠

Multi-Engine Flexibility

Switch seamlessly between in-process llama.cpp (GGUF), local Ollama, and high-throughput vLLM (OpenAI-compatible) backends.

🛡️

Strict Verbatim Grounding

Non-negotiable evidence rule: every generated answer must quote an exact verbatim character span from the source document.

🧩

Zero Token Overlap

HybridChunker enforces clean semantic boundaries without sliding window token bleed, preventing repetitive training noise.

🔢

Numeric Validator

Automatic symbolic cross-check verifies all numbers, percentages, and metrics to eliminate synthetic hallucinations.

🔍

Intelligent Routing

Auto-routes PDFs, Excel sheets, Word files, and presentations to specialized structural extractors (Docling, OpenPyXL, Native).

📦

Training-Ready Formats

One-click export into Alpaca, ShareGPT, and Audit Provenance JSONL with document-level train/val/test splits.

Choose Your Inference Engine

Use whichever model runner matches your infrastructure.

generate_gguf.py
from ForgeDataset import IngestionRouter, HybridChunker, SFTGenerator, QualityGate, DatasetExporter
from ForgeDataset.engines import LlamaCppEngine

# 1. Load local GGUF model directly in-process (no server required!)
engine = LlamaCppEngine(
    model_path="models/qwen2.5-7b-instruct.Q4_K_M.gguf",
    n_ctx=4096,
    n_gpu_layers=-1  # Offload all layers to GPU
)

# 2. Ingest document & chunk
doc = IngestionRouter().route("financial_report.pdf")
chunks = HybridChunker(max_source_context=600).chunk_document(doc)

# 3. Generate SFT dataset with strict evidence grounding
generator = SFTGenerator(engine=engine)
gate = QualityGate()

approved_pairs = []
for chunk in chunks:
    for candidate in generator.generate_from_chunk(chunk):
        evaluated = gate.evaluate(candidate, chunk)
        if evaluated.status == "approved":
            approved_pairs.append((evaluated, chunk))

# 4. Export training dataset
DatasetExporter(output_dir="output").export(approved_pairs, format_type="alpaca")
generate_ollama.py
from ForgeDataset import IngestionRouter, HybridChunker, SFTGenerator, QualityGate, DatasetExporter

# Connect to local Ollama daemon with automatic VRAM purging
generator = SFTGenerator(
    engine="ollama",
    model="qwen2.5:7b-instruct",
    base_url="http://127.0.0.1:11434"
)

doc = IngestionRouter().route("system_architecture.docx")
chunks = HybridChunker().chunk_document(doc)

pairs = [(gate.evaluate(cand, c), c) 
         for c in chunks 
         for cand in generator.generate_from_chunk(c)]

DatasetExporter(output_dir="output").export(pairs, format_type="sharegpt")
generate_vllm.py
from ForgeDataset import SFTGenerator
from ForgeDataset.engines import OpenAICompatibleEngine

# High-throughput batch inference with vLLM or LM Studio
engine = OpenAICompatibleEngine(
    model="Qwen/Qwen2.5-7B-Instruct",
    base_url="http://localhost:8000/v1"
)

generator = SFTGenerator(engine=engine)
# Ready to process high-volume documents
