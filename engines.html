Multi-Engine LLM Inference

ForgeDataset eliminates backend lock-in with a modular engine abstraction.

1. llama.cpp (GGUF In-Process)

Direct In-Process

Run local quantized GGUF weights directly in your Python process with llama-cpp-python. No external background daemons or Docker containers required.

Python
from ForgeDataset import SFTGenerator
from ForgeDataset.engines import LlamaCppEngine

# Point directly to your downloaded .gguf model file
engine = LlamaCppEngine(
    model_path="models/qwen2.5-7b-instruct.Q4_K_M.gguf",
    n_ctx=4096,         # Context window
    n_gpu_layers=-1     # -1 offloads all layers to GPU (CUDA or Metal)
)

generator = SFTGenerator(engine=engine)
pairs = generator.generate_from_chunk(chunk)

2. Ollama (Local Daemon)

REST API

Connect to your local Ollama instance with automated sequential VRAM purging (keep_alive: 0) to allow running on limited ~8GB VRAM consumer GPUs.

Python
from ForgeDataset import SFTGenerator

generator = SFTGenerator(
    engine="ollama",
    model="qwen2.5:7b-instruct",
    base_url="http://127.0.0.1:11434"
)
pairs = generator.generate_from_chunk(chunk)

3. OpenAI-Compatible (vLLM / LM Studio / LocalAI)

High Throughput

Use any server implementing standard /v1/chat/completions. Ideal for high-throughput batching on server clusters using vLLM.

Python
from ForgeDataset import SFTGenerator
from ForgeDataset.engines import OpenAICompatibleEngine

engine = OpenAICompatibleEngine(
    model="Qwen/Qwen2.5-7B-Instruct",
    base_url="http://localhost:8000/v1"
)

generator = SFTGenerator(engine=engine)
pairs = generator.generate_from_chunk(chunk)

4. Implementing a Custom Engine

To integrate custom models, Hugging Face pipelines, or proprietary backends, subclass LLMEngine:

custom_engine.py
from ForgeDataset.engines import LLMEngine
from typing import Dict, Any, Optional

class MyCustomEngine(LLMEngine):
    def is_available(self) -> bool:
        return True

    def generate(
        self,
        prompt: str,
        system: Optional[str] = None,
        json_format: bool = True,
        temperature: float = 0.3,
        **kwargs: Any
    ) -> Dict[str, Any]:
        # Invoke your model and return parsed JSON
        return {
            "qa_pairs": [
                {
                    "question": "What is the primary formula?",
                    "answer": "The primary formula is E=mc^2.",
                    "evidence": "E=mc^2"
                }
            ]
        }

generator = SFTGenerator(engine=MyCustomEngine())
